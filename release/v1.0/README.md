# Release v1.0

Prototype release, exported from EasyEDA Pro. **Not validated and not ordered.** The layout passes EasyEDA DRC, but the board has not been fabricated or tested.

| File | Content |
|---|---|
| `gerber-v1.0.zip` | Gerber and drill files, two layers. Upload this to the fab |
| `BOM.md` | Parts list with order links |
| `bom-v1.0.csv` | EasyEDA BOM export, UTF-16 |
| `placement-v1.0.csv` | Part positions, UTF-16 |
| `SHA256SUMS` | Checksums |

The order instruction is in the [root README](../../README.md#ordering).
